# Lumen TV — واجهة رئيسية مخصّصة لـ Android TV / Google TV

شاشة رئيسية بديلة للتلفزيون، مستوحاة من فكرة واجهة LG / Apple TV:

- **ساعة كبيرة وتاريخ وطقس** (يتحدد مكانك تلقائياً، ويحتاج إنترنت) أعلى الشاشة (بالعربي تلقائياً إذا لغة الجهاز عربية)
- **خلفيات**: 6 خلفيات مدمجة (غروب، صحراء، محيط، شفق، ليل، لافندر) أو **صورتك الخاصة**، مع حركة تكبير بطيئة تعطي إحساساً حيّاً
- **صف المفضلة**: بطاقات التطبيقات تكبر وتلمع عند التحديد بالريموت
- **صف "آخر ما فتحته"**: يظهر تلقائياً حسب استخدامك
- **درج كل التطبيقات**: شبكة فيها كل تطبيقات الجهاز
- **لوحة إعدادات مختصرة**: الخلفية، التعتيم، نظام 24 ساعة، الشبكة، الصوت، إعدادات الجهاز
- **ضغطة مطوّلة** (أو زر القائمة ☰) على أي تطبيق: إضافة/إزالة من المفضلة، تحريك، معلومات، إلغاء تثبيت
- يدعم العربية (من اليمين لليسار) والإنجليزية
- بدون أي مكتبات خارجية — ملف APK صغير وخفيف على التلفزيون

---

## 1) بناء ملف APK

### الطريقة الأسهل: GitHub (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على GitHub وارفع هذا المجلد كاملاً.
2. ادخل على تبويب **Actions** — البناء يبدأ تلقائياً (أو اضغط **Run workflow**).
3. بعد دقائق، افتح آخر تشغيل وحمّل **LumenTV-apk** من قسم Artifacts.

### أو: Android Studio
افتح المجلد في Android Studio، ثم: **Build → Build APK(s)**.
الملف يطلع هنا: `app/build/outputs/apk/debug/app-debug.apk`

---

## 2) التثبيت على التلفزيون

فعّل وضع المطوّر على التلفزيون:
**الإعدادات ← النظام ← حول ← اضغط على "إصدار نظام التشغيل" 7 مرات**، ثم فعّل **تصحيح أخطاء USB / ADB** من خيارات المطوّر.

من الكمبيوتر (نفس شبكة الواي فاي):

```bash
adb connect IP_التلفزيون:5555
```

```bash
adb install -r app-debug.apk
```

> بديل بدون كمبيوتر: ارفع الملف على Google Drive وثبّته بتطبيق **Downloader** أو **Send Files to TV**.

---

## 3) جعلها الشاشة الرئيسية الافتراضية

بعد التثبيت اضغط زر **الرئيسية** في الريموت: إذا ظهر لك خيار، اختر **Lumen TV** ثم **دائماً**.

إذا ما ظهر خيار (وهذا الشائع في Google TV)، عطّل الواجهة الأصلية بـ ADB:

**Google TV** (مثل Chromecast with Google TV، وشاشات TCL وHisense وSony الحديثة):
```bash
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
```

**Android TV القديم:**
```bash
adb shell pm disable-user --user 0 com.google.android.tvlauncher
```

### للرجوع للواجهة الأصلية في أي وقت
```bash
adb shell pm enable com.google.android.apps.tv.launcherx
```

```bash
adb shell pm enable com.google.android.tvlauncher
```

> ⚠️ التعطيل آمن وقابل للتراجع بالكامل بالأمر أعلاه، لكن تحديثات النظام أحياناً ترجّع الواجهة الأصلية — أعد أمر التعطيل إذا صار هذا.
> بعض أجهزة Google TV يكون فيها زر "Google" أو "التطبيقات" في الريموت مربوطاً بالواجهة الأصلية، فقد لا يعمل بعد تعطيلها.

## طريقة الاستخدام بالريموت

| الزر | الوظيفة |
|---|---|
| الأسهم | التنقّل بين التطبيقات |
| OK | فتح التطبيق |
| ضغطة مطوّلة على OK، أو زر ☰ | خيارات التطبيق (مفضلة، تحريك، إلغاء تثبيت) |
| زر ⚙ أعلى الشاشة (أو ☰ خارج البطاقات) | لوحة الإعدادات |
| رجوع | إغلاق اللوحة المفتوحة |
| الرئيسية | الرجوع لأول تطبيق في المفضلة |

**تغيير الخلفية لصورتك:** الإعدادات ← "اختيار صورة من الجهاز". إذا التلفزيون ما فيه مدير ملفات، ثبّت **X-plore File Manager** من المتجر أولاً.

## بنية المشروع

```
app/src/main/java/dev/lumen/launcher/
├── MainActivity.kt   الشاشة الرئيسية، درج التطبيقات، لوحة الإعدادات
├── Ui.kt             بطاقة التطبيق وتأثيرات التحديد
├── Data.kt           قراءة التطبيقات المثبّتة والإعدادات المحفوظة
└── Wallpapers.kt     الخلفيات المدمجة وتحميل صورتك
```

**أفكار للتطوير لاحقاً:** توصيات المحتوى من داخل كل تطبيق (تحتاج صلاحيات نظام)، اختصار لمداخل HDMI.
